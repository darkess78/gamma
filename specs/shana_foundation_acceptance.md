## Connected behavior implemented

The current private session supplies the scheduled review's conversation context.
Focused attention suppresses interruptions without prohibiting explicitly
permitted quiet practice. A finite permission limits exercises, starts, attempts,
reviews and elapsed time. Waiting is a valid model choice.

Conversation can reserve a later exercise, switch to it, pause it before starting,
and resume either activity using its original scope. A request reserves its start
once. Resume does not replenish attempts or extend its deadline. Saved edits
survive a real process exit and are checked without generating them again.
Authorized workers can finish while Shana sleeps; wake reconciles their results
once. Progress answers select one activity and use its verified evidence.

Operational lookup and recovery include old unfinished work regardless of the
recent-history limit. Model context and the dashboard retain bounded presentation
views. Current or unfinished activities receive priority in those views.

Private generation now uses a schema derived from the shared turn model.
Its communicating, silent and deferred branches keep action/delivery pairs
coherent. Every nested decision field is required; operation names belong in
`state_updates.activity_action`. Tools, memory writes, speech and presentation
hint channels remain unavailable in this slice. Ordinary adapter requests keep
their existing defaults. This uses Ollama's documented
[schema output format](https://docs.ollama.com/capabilities/structured-outputs)
and retains the existing parser, privacy checks and bounded repair.
